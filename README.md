# ✈️ מעקב אישורים ליציאה לשליחות

**🔗 האתר:** https://ctcvyf8fbp-maker.github.io/yuval/

## עדכון שוטף – בגיליון Google (לא כאן)
שמות, סטטוסים ותאריכים מתעדכנים **בגיליון Google Sheets**. האתר מתעדכן לבד תוך כ-5 דקות.

| בגיליון | מה זה עושה באתר |
|---|---|
| עמודה לכל שליח/נסיעה (כותרת בשורה 7, למשל „יובל – סטטוס”) | לשונית עם סבבי האישורים |
| תא סטטוס ריק | נחשב „ממתין” |
| „-” או „לא רלוונטי” בתא | האישור לא מופיע בלשונית הזו |
| כותרת עם המילה **טפסים** / **מידע** / **ליסט** | לשונית טפסים / מידע / צ׳ק ליסט (בלי סבב אישורים) |
| שורה 6: „תיקיית מסמכים” + קישור OneDrive | כפתורי השליחה מובילים לתיקייה של השליח |
| שורות שבעמודה A כתוב „מסמכים” ובעמודה C שם המסמך (טופס 101, כתב התחייבות, תלוש שכר, צ׳ק ליסט…) | בלשונית הטפסים מופיע ✓ התקבל / ⏳ בטיפול / חסר |
| תאריך ליד אישור שעוד לא אושר | „ממתין X ימים”; מעל 7 ימים – באדום |

## פעולות מהירות
| מה רוצים לעשות | לוחצים כאן |
|---|---|
| ✏️ הגדרות (קישורים, טפסים, כותרות) | [עריכת data.js](https://github.com/ctcvyf8fbp-maker/yuval/edit/main/data.js) |
| 📎 להעלות קבצים | [העלאה](https://github.com/ctcvyf8fbp-maker/yuval/upload/main) |
| 👀 לפתוח את האתר | [מעבר לאתר](https://ctcvyf8fbp-maker.github.io/yuval/) |

אחרי כל העלאה: **Commit changes**, מחכים 1–2 דקות, ומרעננים (במחשב: Option + Command + R; בטלפון: סוגרים ופותחים את הלשונית).
