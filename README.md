# ✈ מעקב אישורים ליציאה לשליחות

אתר קטן שמציג את מצב האישורים לכל נסיעה: כרטיס עלייה למטוס, מפת טיסה שבה המטוס עומד בשלב הנוכחי, ורשימת הסבבים.

## הקבצים

| קובץ | מה יש בו | צריך לגעת? |
|---|---|---|
| `data.js` | כל הנתונים: נסיעות, סבבים, שמות, סטטוסים | **כן – רק אותו** |
| `index.html` | מבנה הדף | לא |
| `style.css` | צבעים ועיצוב | רק אם רוצים לשנות מראה |
| `app.js` | הלוגיקה (מטוס, ספירה, צבעים) | לא |

## איך מעדכנים אישור

1. ב-GitHub לוחצים על `data.js` ואז על סמל העיפרון ✏️.
2. מוצאים את השורה, למשל:
   `{ role: "משרד הביטחון", status: "ממתין", date: "" }`
3. משנים ל: `status: "אושר", date: "2026-11-05"`
4. מעדכנים למעלה את `LAST_UPDATED` לתאריך של היום.
5. לוחצים **Commit changes**. האתר מתעדכן תוך דקה-שתיים.

סטטוסים אפשריים: `"אושר"`, `"ממתין"`, `"בטיפול"`, `"נדחה"`.

## איך מעלים את כרטיס הטיסה ואישור השליחות

1. שומרים את התמונה במחשב בשם **flight.jpg** (כרטיס הטיסה) או **mission-approval.jpg** (אישור השליחות).
2. ב-GitHub: **Add file ← Upload files**, גוררים את התמונה, **Commit changes**.
3. זהו. התמונה תופיע באתר תוך דקה-שתיים. עד אז כתוב "טרם הועלה".

רוצים להחליף תמונה? מעלים קובץ חדש עם אותו שם בדיוק, והוא מחליף את הקודם.
קובץ PDF? מעלים אותו (למשל `flight.pdf`) ומשנים ב-`data.js` את השם בשורה `flight: "flight.pdf"`.

## איך מוסיפים נסיעה

מעתיקים בלוק שלם של נסיעה ב-`data.js` (מ-`{` שאחרי `title` ועד ה-`}` שסוגר אותו), מדביקים אחריו עם פסיק, ומשנים פרטים. טאב חדש יופיע לבד.
