# ✈️ מעקב אישורים ליציאה לשליחות

**🔗 האתר:** https://ctcvyf8fbp-maker.github.io/yuval/

## פעולות מהירות

| מה רוצים לעשות | לוחצים כאן |
|---|---|
| ✏️ לעדכן שם שליח, יעד, תאריך או סטטוס | [עריכת הנתונים](https://github.com/ctcvyf8fbp-maker/yuval/edit/main/data.js) |
| 📎 להעלות כרטיס טיסה או אישור שליחות | [העלאת מסמך](https://github.com/ctcvyf8fbp-maker/yuval/upload/main) |
| 📤 לראות מסמכים ששלחו אלייך | [Dropbox – בקשות קבצים](https://www.dropbox.com/requests) |
| 👀 לפתוח את האתר | [מעבר לאתר](https://ctcvyf8fbp-maker.github.io/yuval/) |

אחרי כל שינוי: לוחצים **Commit changes**, מחכים 1–2 דקות, ומרעננים את האתר (Command + Shift + R).

## כפתור "שליחת מסמך"

כל מי שנכנס לאתר יכול ללחוץ **📤 שליחת מסמך** ולהעלות קובץ. הקבצים מגיעים ל-Dropbox (תיקייה **שילוח**), ושם רק את רואה אותם.
כדי שמסמך יופיע באתר – מורידים אותו מ-Dropbox, משנים את השם (לפי הטבלה למטה) ומעלים לכאן.

## טפסים למילוי

לטופס איש הקשר יש גם **מילוי מקוון** (`form-contact.html`): השליח ממלא בדפדפן, חותם עם האצבע, שומר כ-PDF ושולח ב„שליחת מסמך”. הפרטים לא נשמרים באתר.

השליחים יכולים להוריד טפסים מהאתר, למלא ולשלוח חזרה דרך „שליחת מסמך”.

1. משנים את שם הקובץ במחשב ל-**form-1.pdf** (טופס שני – form-2.pdf, שלישי – form-3.pdf).
2. מעלים אותו כאן דרך **העלאת מסמך**. הטופס מופיע באתר לבד.
3. כדי לשנות את השם שמופיע באתר (במקום „טופס 1”) – ב**עריכת הנתונים** משנים את `title: "טופס 1"`.
4. קובץ Word? משנים גם את הסיומת באותה שורה: `file: "form-1.docx"`.
5. הערה מתחת לטופס (למשל „איש הקשר חייב להיות מדרגה ראשונה”) – משנים את `note: "..."`. בלי הערה: `note: ""`.

## שמות המסמכים

לפני ההעלאה משנים את שם הקובץ במחשב:

| | כרטיס טיסה | אישור שליחות |
|---|---|---|
| שליח 1 | `flight-1.jpg` | `mission-approval-1.jpg` |
| שליח 2 | `flight-2.jpg` | `mission-approval-2.jpg` |
| שליח 3 | `flight-3.jpg` | `mission-approval-3.jpg` |

קובץ PDF או PNG? מעלים אותו, ואז בעריכת הנתונים משנים את הסיומת בשורה המתאימה, למשל `flight: "flight-1.pdf"`.
להחלפת מסמך – מעלים קובץ חדש עם אותו שם בדיוק.

## 📊 עדכון אישורים מגיליון (מומלץ)

אפשר לעדכן הכול מגיליון – בלי לגעת בקוד:

1. ב-Google Drive: **חדש ← העלאת קובץ** ← בוחרים את `גיליון-סנכרון-אישורים.xlsx`, ופותחים אותו עם **Google Sheets**.
2. בגיליון: **קובץ ← שיתוף ← פרסום באינטרנט** ← בוחרים את הגיליון **אישורים** ואת הפורמט **ערכים מופרדים בפסיקים (.csv)** ← **פרסום**.
3. מעתיקים את הקישור שמתקבל ומדביקים אותו ב[עריכת הנתונים](https://github.com/ctcvyf8fbp-maker/yuval/edit/main/data.js) בשורה `const SHEET_CSV_URL = "";` בין המירכאות ← **Commit changes**.

מעכשיו כל שינוי בגיליון (גם מהטלפון) מופיע באתר תוך כ-5 דקות. בתחתית האתר יופיע „✔ מסונכרן עם הגיליון”.

## עדכון סטטוס ידני (בלי גיליון)

בעריכת הנתונים מוצאים את השורה של האישור ומשנים:

`status: "ממתין"` ← `status: "אושר", date: "2026-11-05"`

סטטוסים אפשריים: `"אושר"` · `"ממתין"` · `"בטיפול"` · `"נדחה"`

## מה יש כאן

| | מה זה | נוגעים? |
|---|---|---|
| `data.js` | כל הנתונים: שליחים, סטטוסים, תאריכים | **כן – רק בו** |
| `index.html` | הדף הראשי של האתר | לא |

## אם משהו נשבר

- גרשיים בתוך טקסט כותבים עם לוכסן: `"רמ\"ח תכנון"`.
- כל שורה ברשימה מסתיימת בפסיק, חוץ מהאחרונה.
- דף ריק אחרי עדכון? כנראה חסר פסיק או מירכאה. אפשר לחזור לגרסה הקודמת דרך **History** בקובץ data.js.
